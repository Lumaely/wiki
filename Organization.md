
This project will be following a **Github Project**, creating issues for each features, and sub-issues for each fragment of the feature.

---

### Meets

**Mentor meetings :** Occur every 6 weeks. An archive must be submitted 48 hours in advance.
**Pedagogical meetings :** Occur every 6 weeks with the Epitech team. 

These sessions are staggered so that the group has a meeting every 3 weeks. Additionally, the group will meet whenever they deem it necessary.

---
### Workflows

- **New feature :**
	- Create a new issue
	- Create its sub-issues (see [[Development-standards]])

- **Bug report :**
	- Create a new issue 
	- Create its sub-issues

A new branch must be created for each new issues.
Target date must be set for **all** issues except for **Bug reports**?.

> [!IMPORTANT]
> **Pull requests** will be ignored if the submission check list is not complete.
